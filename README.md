# 控制台爱心代码 (Console Love Heart)

## 📖 项目简介
这是我在学习 Java 循环与条件控制时编写的一个创意趣味小项目。程序利用多层嵌套循环和坐标数学运算，在控制台中通过字符 `*` 与空格绘制出一个爱心图案，并在最后送上专属表白语。

## 🚀 功能特性
- **纯控制台绘制**：无需图形化界面，仅仅通过 `System.out.print()` 配合循环，在终端中绘制出对称的爱心形状。
- **数学逻辑实现**：
  - 上半部分采用双圆弧模型，通过 `p6` 和 `p7` 两个中心点，控制左右两瓣的扩展与收缩。
  - 下半部分采用对称递减模型，由宽变窄，汇聚成心形尖尖。
- **专属互动**：绘制完成后打印“爱你哦~”作为彩蛋，适合作为特别的节日礼物或表白代码。

## 💻 技术栈
- **语言**: Java SE
- **核心考点**: 嵌套循环、条件判断（if-else）、数学逻辑与算法抽象、控制台输出排版。
